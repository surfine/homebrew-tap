# surfine/homebrew-tap

Homebrew casks for [WindowShade](https://github.com/surfine/WindowShade).

```bash
brew install --cask surfine/tap/windowshade
```

WindowShade updates itself from its menu, so you don't need `brew upgrade` for it. `brew uninstall --zap` removes preferences, caches and logs but leaves `~/Library/Application Support/WindowShade` (your file shelf) in place.
